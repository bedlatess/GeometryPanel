# Android 安装包

Android 8.0 及以上安装本项目 GitHub Release 的 `GeometryPanel-版本.apk`。容器固定使用 `https://bedlatess.github.io/GeometryPanel/`，与 iPhone 网页共用登录、车况、地图、车控、设置和任务界面。网页业务走现有网页更新流程；原生能力变化需要更新 APK。`panel-android/` 保留作前期参考。

浏览器和 APK 各自保存登录。同一签名且版本号更高的 APK 可覆盖升级，保留本机资料；卸载会清除资料。首次打开需联网。

## 0.5.0 功能

- **后台车况与历史**：独立本机加密库支持最多 8 账号、每账号 16 车。明确开启后使用可见前台服务，按旧协议 60/150/300 秒读取；另有 15 分钟系统后备任务。充电、低电量、离线、消息和胎压提醒按开关去重，认证过期暂停请求。每车保留 500 个电池点、100 段充电记录、200 项事件，可分页查看和明确清除。系统省电、通知授权和前台服务时限仍会影响实际刷新。
- **记录质量**：依据 `home.refreshTime`、`battery.refreshTime` 标记时间未知、陈旧和未来。陈旧/时间未知不推断充电转换，未来样本不记历史。首次充电开始时间仅代表开始观测，标记 `estimated`；超过五分钟缺测或状态未知的会话标为 `unknown`，不推成充满。
- **多账号自动任务**：可选签到、连续签到奖励、点赞、分享、文字发帖和精确清理，默认关闭；保存不立即执行，定时由系统调度，手动运行需确认。写请求前持久化当天尝试门闩，结果未知不盲重发。点赞需额外确认旧接口可能切换已有赞；清理必须证明是本次新发布、同作者同内容且唯一的帖子。结果步骤/诊断不含内容、文章 ID或凭据。
- **四种组件与快捷操作**：1×1、2×2、4×2、4×4 显示电量、续航、电压和时间。每个组件独立绑定本机车辆 ID，只选同车网页/后台快照。允许控制时提供刷新、上电解锁、关电上锁、鸣笛和座桶入口；HMAC绑定当前账号/车辆 epoch和凭据摘要，账号移除、停用或变化后旧入口失效。
- **蓝牙与靠近提醒**：恢复旧包 BLE1 的扫描、认证、登记 ACK、配对查询和读数；仅连接已核对的本人车辆，云钥匙资料五分钟有效。车型读数仍需实车核对，不触发低电量通知。靠近服务只提醒，过期或换车停止。BLE2/3配对、自动开锁没有补猜指令。
- **仪表壁纸和投屏**：实际车型模板支持两张照片、本地 ZIP、白名单原始模板 ZIP。照片本机裁切，下载校验可用大小/MD5，严格验证 `1.png`/`2.png`、PNG尺寸、CRC和ZIP边界。确认后才连接已核对 P2P对端发送；离开取消等待/传输，已发送则提示结果未知。投屏需系统 MediaProjection授权，可通知栏停止；恢复三通道 H.264拉帧，上限1280×720、30帧、4Mbps，无音频/反向触控。
- **AE5I Gemini OTA**：仅旧包标明的5寸Sunplus Gemini。选择本地 `.bin`，检查大小/MD5，手动连唯一仪表 Wi-Fi，固定 `192.168.0.1:10086` 读取版本后原生二次确认才发固件。热点不等于面板所选车辆，MD5不证明厂商签名或兼容。已发送后失败/取消显示结果未知，最终校验响应也不等于升级成功。没有内置固件、自动刷写、续传或回滚。
- **扫码和导出**：系统拍照或选本机图片后用 ZXing识别，可将仪表配对码加密绑定当前车辆，未知二维码不自动打开。原 ZIP仅从固定HTTPS对象存储下载，可检查/保存。车况PNG只接网页生成的纯base64，解码≤1MiB、尺寸≤2048×2048，验证PNG和实际解码后经系统创建文档保存；不抓整页截图。
- **诊断和APK更新**：系统保存脱敏诊断，不含账号/车辆标识、位置、消息、发帖内容、原始HTTP或钥匙。固定读取本仓库最近20个已发布Release，含验收预发布版、排除草稿，选最高可识别版本APK。下载后核对包名、版本代码和当前安装同证书，再交系统安装器确认；不接任意更新地址。
- **官方登录临时导入**：用户在原生页主动确认后，系统VPN只允许 `com.cfmoto`，最长十分钟，通知栏可停。只在ClientHello SNI为 `h5.zeehoev.com` 时解TLS，观察 `/H5/baseInfo` 认证响应身份，其它TLS原样转发。设备生成独立本机CA/叶证书，需要手动安装公开CA；上游保持系统CA和HTTPS主机名验证。若官方拒绝用户证书/证书锁定，此方式无法读取，使用面板验证码登录。资料通过固定车辆列表核验后加密暂存十分钟；普通状态不回传凭据，用户再确认后仅交给当前正式面板一次，由网页加密保存。
- **可选保活模块**：导出针对本包及 `.debug` 的 Magisk/KernelSU ZIP，保留已授权旧实现的策略备份、互斥、卸载恢复和作者归属。只读无秘密的开启标记/心跳，不读账号库；不申请root、不自动安装。9个资源已打包，6个shell入口只做语法检查，没有执行或安装。

## 正式网页快照

除共用PWA缓存外，Android从唯一正式来源下载 `sw.js` 列出的完整公开静态文件，全部完成并校验引用关系后原子提交，失败保留旧快照。主页面加载失败时仍使用同一正式HTTPS地址和桥来源，由原生返回静态文件；不把旧作者域名或镜像作为受信页面。

回退会话固定同一份manifest和目录。刷新/清除不删除使用中的文件，离开后才清理。缓存仅限HTML/JS/CSS/图标/manifest，不缓存账号API、登录或截图。“更新”原生页提供状态、刷新和清除。真实Android WebView运行回退仍需设备验收。

## 连接与资料边界

桥使用 `WebViewCompat.addWebMessageListener`，只接受正式origin顶层主页面且路径在 `/GeometryPanel/`，地图iframe不可调用。检查白名单、ID、并发、大小、页面生命周期；配置参数最多256KiB、普通参数16KiB，只有车况PNG导出允许约1.5MiB base64请求。不提供通用URL/TCP/文件/root执行桥。

账号、钥匙、配对和临时捕获材料用Android Keystore AES-GCM，存于不参与备份的目录。监控/任务明确配置后才调度；开机只恢复已开启的系统任务，不自动连接蓝牙、投屏、OTA或VPN。忘记即时车辆材料与停用独立后台账号是不同范围，退出全部账号时网页显式清空原生账号库。

P2P核对组主MAC、私有IPv4、真实接口及子网，绑定实际网络/源地址；手机不暴露P2P Network时检查接口，拒绝VPN/竞争网络/路由，不回退默认路由。OTA使用独立固定热点。临时登录VPN另外获得系统同意。

权限按需申请，文件用系统选择器，无通用存储权限。主WebView关闭文件/content访问、混合内容、定位、调试，不绕过证书错误；外部HTTPS交系统浏览器。禁用备份/设备迁移。返回键走网页弹窗自身关闭/取消流程。

## 构建与验证

需要Node.js24、JDK21、Android SDK36/build-tools36.0.0。在网页工程根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-android.ps1
```

当前0.5.0：**43项JVM测试、34个真实NativeClient方法/请求ID、4个返回场景通过**，release lint 0错误，debug构建通过。TLS测试只在本机loopback使用合成CA和固定文字验证ClientHello回放/SSLEngine加解密；TCP/DNS、chunked/gzip、时间质量、组件跨车隔离、预发布更新、false写响应拒绝、快照使用保护都有合成回归。

24项lint警告主要为中文工具文案、组件样式/字号、依赖更新提示及BouncyCastle未使用的EST helper；该helper不用于网络客户端。VPN的systemExempted仅使用单项lint说明：系统已配置VPN符合该类型，入口和服务都检查 `VpnService.prepare()==null`，不添加无关闹钟权限。完整公开记录见 `verification/android-check.json`。

版本读取package.json，0.5.0对应5000。产物：

```text
android/app/build/outputs/apk/release/GeometryPanel-0.5.0.apk
android/app/build/outputs/apk/release/verification.json
```

`android/.signing/` 是Git忽略的稳定签名资料，应私密备份整个目录，不能上传/发聊天。脚本发现缺失会报错，不悄悄更换。更新核验使用公开证书，不读取签名私钥。CI位于 `.github/workflows/android.yml`，默认是独立 `.debug` 包；同一签名secrets配置后才生成可覆盖升级的正式包。

当前没有进行Android实机/模拟器、官方登录/VPN、真实流量捕获、BLE、仪表、车辆控制、后台时长或更新安装验证。静态恢复、编译和合成测试不等于设备或服务端验收，统一进入最后集中验收。
