# 几何面板 iOS

共用正式网页 `https://bedlatess.github.io/GeometryPanel/`，原生 Swift 只负责系统能力。需要 iOS 16 或更高版本。没有加入自己的账号服务器，账号仍由网页的本机保险库存储。

## 两个 IPA

- `GeometryPanel-版本-unsigned.ipa`：常规版。供使用者自签，不需要 App Groups；含网页、蓝牙、通知和仪表能力。
- `GeometryPanel-版本-widget-unsigned.ipa`：可选桌面组件版。额外含 WidgetKit 扩展和 App Groups 配置；自签工具必须能处理扩展、App Groups 和相应授权。

两者都没有苹果签名，不能直接点击安装，也不承诺任何第三方自签工具均支持。自签者将 IPA 导入自己的工具、用自己的签名资料签署后安装。修改包标识时，工具需要一致处理主应用和扩展。组件版的组名在 `Resources/App.entitlements`、两个 Info.plist 的 `GeometryAppGroup` 中保持一致；有开发者账号的维护者应换成自己团队已创建的 App Group。基础版完全不依赖这个能力；不会签名时继续在 Safari 打开网页并添加到主屏幕。

签名密码、证书、Apple 账号不会进入仓库或构建流程。这里没有下载、远程注册或代签服务。

## 已实现的能力

| 能力 | 行为和边界 |
|---|---|
| 网页容器 | 正式 HTTPS 页面、失败重试、外链交给系统浏览器；主页面原生桥只允许本仓库路径和主 frame |
| 蓝牙扫描与连接 | 先扫描已知 B354 服务；没有结果时仅在前台扫描附近设备。用户在车旁选择并原生确认，连接后必须有 B354/B356/B357 服务与特征 |
| 蓝牙认证 | 恢复原包外帧、protobuf、两步 AES-ECB challenge-response；写入逐块等待回复，事务和连接都有超时 |
| 2.0 登记与查询 | 车主校验、五分钟云资料、云感应开关已开启；本机 8 字节身份保存在 Keychain。登记 ACK、云保存、车端查询分别处理 |
| 近距离车况 | 遥测及仪表流订阅；单位未验证的字段不猜。不会发送原包未包含的“开锁”帧 |
| 连接提醒 | 用户主动开启、单独请求通知权限。保持已认证连接时可在系统允许范围内处理断连提醒；不承诺自动开锁、后台无限运行或关闭应用后继续提醒 |
| 低电量通知 | 根据当前页面最近读取的车况判断；前台也可显示通知。没有将网页 token 交给后台，也没有伪装成后台实时云监控 |
| 桌面组件 | 仅组件版、签名权限有效时显示本机上次读取的电量和续航；无凭据、VIN 或位置。打开面板刷新，不冒充实时后台数据 |
| 仪表壁纸 | 从网页选择模板取得真实编号/显示配置，系统选两张图、本机重新编码 PNG，生成仅含 `1.png/2.png` 的 ZIP，再按 10950 协议传输和确认 |
| 仪表投屏 | 用户系统录屏授权、ReplayKit 采集本应用、VideoToolbox H.264、三通道控制/协商/车端拉帧；红色按钮可停止，进入后台自动停止 |

蓝牙 MAC 在 iOS 不可读取，因此不能照搬 Android 按 MAC 直连。3.0 钥匙和旧版已经标明未验证的自动解锁不能声称迁移完成。iOS 系统配对由 CoreBluetooth 在特征要求加密时提示，应用不能调用 Android 的 `createBond`。

仪表要求用户手动连接车辆热点，当前连接固定 `192.168.0.1` 的已知端口并要求 Wi-Fi 路径；接受车端连接也只接受该 IP。iOS 无通用 Wi-Fi Direct，部分车型可能无法提供兼容热点或拒绝 iOS 投屏握手。原生确认明确提醒热点身份不能由 VIN 自动证明；不将这些条件写成实车已通过。投屏不含系统其它应用、音频、触摸反控和固件升级。

## 本地维护和构建

需要 Mac/Xcode、可用的 iOS 模拟器和 XcodeGen：

```sh
brew install xcodegen
bash ios/scripts/build.sh
```

GitHub Actions `Verify iOS native and unsigned IPA` 在 macOS 构建。脚本从主项目 `package.json` 同步版本，先跑模拟器上的 XCTest，再构建两个 arm64 设备版。`ios/build/packages/` 包含两个 unsigned IPA、SHA256 和 `ios-verification.json`。记录当前提交、Xcode、模拟器结果、设备构建及每个 IPA 的哈希；没有真实 iPhone 或车辆时，不写成实机通过。

Xcode 工程由 `project.yml` 生成，不手工维护 pbxproj。原生协议和网页桥 v1 由固定白名单维护，不提供任意 TCP、任意请求代理、任意 JavaScript 执行或钥匙读取方法。地图 iframe 不能访问桥。账号切换、退出、页面导航和前后台转换会清理原生操作，避免旧异步回调继续车控。

## 最后集中验收

由用户完成一次连续场景：自签常规版后打开/重开登录；在车旁刷新蓝牙资料、扫描选择、认证、查询并观察近距离数据；主动开启连接提醒后离开车辆观察通知；连接仪表热点，选择模板及两张图推送，再尝试授权投屏并停止。组件版只在自签工具支持 App Groups 时增加组件确认。功能结果以手机和车辆实际表现为准，自动测试使用合成数据。
