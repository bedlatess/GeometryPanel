## 1. 设计原则

1. **少即是贵。** 每屏只有一个主角，一个主要操作，其余都退后。删得掉的元素一律删掉。
2. **说人话。** 界面上的字是“车告诉你的话”，不是“系统字段”。不写解释，不写开发用语。
3. **诚实。** 旧数据就说旧，发出不等于完成，没有数据就写“—”或不显示。这条优先于美观。
4. **像系统一样可预期。** 返回、弹层、开关、列表、选择器都用 iOS 用户熟悉的样子和手感，只在三处表现个性：车图舞台、滑动条、车型字标。
5. **每个像素都有理由。** 不加装饰性的边框、渐变、阴影、发光；层级靠留白、字号、字重和底色区分。

### 1.1 禁止事项（违反任何一条，审计不通过）

| 不允许 | 改用 |
|---|---|
| 竖分隔线、“·”“｜”“/” 等符号分隔信息 | 留白（全角空格或 12～16 px 间距）、换行、分组 |
| “标签：数值”式的小字堆叠（例如“预计续航 91 km　电压 76.4 V”并排） | 一句话（“可行驶 91 km”），或放进列表行（左标签右数值） |
| 浏览器原生控件：`<select>`、`<input type=date/month/number>`、`<details>`、`<table>` | Ionic 对应组件：`ion-select`（action-sheet 形式）、`ion-datetime`、`ion-picker`、`ion-accordion` 或二级页、列表 |
| 没有底框的灰色文字按钮 | `ion-button`（实心、浅底、或列表里的动作行） |
| 每屏超过一个实心主按钮 | 次按钮用浅底，或放进列表 |
| 卡片套卡片 | 一层卡片 |
| emoji、感叹号、“您”“我们”“哦”“啦”，营销语 | — |
| 空状态之外的说明段落；多于一行的提示 | 必要说明放 ⓘ 弹层 |
| 页面中间出现红色危险按钮 | 危险操作一律放在页面最后一组 |
| 一行超过 120 个字符的代码；单个 `.vue` 文件超过 300 行 | 拆分组件 |

## 3. 动效与触感

动效只用来解释变化，不做装饰。所有参数集中写在 `src/theme/motion.ts`。

### 3.1 基础曲线

| 名称 | 值 | 用在 |
|---|---|---|
| `ios` | `cubic-bezier(.32,.72,0,1)` | 页面推入推出、弹层（Ionic iOS 默认，不改） |
| `out` | `cubic-bezier(.2,.8,.2,1)` | 淡入、位移 |
| `spring` | 刚度 400、阻尼 32、质量 1（约 350 ms 收敛，无明显过冲） | 滑块回弹、按压恢复 |
| `snap` | 180 ms `out` | 滑块吸附到终点 |

### 3.2 动效清单

| 场景 | 动效 |
|---|---|
| 页面切换 | Ionic iOS 推入推出（约 540 ms），上一页向左移 30% 并变暗；iOS 网页版和 App 支持从左边缘右滑返回，跟手 |
| 底栏切换 | 无动画，直接切换；再次点击当前栏，滚回顶部（带系统惯性） |
| 大标题 | 一级页上滑时，34 号大标题收进导航栏，变成 17 号居中标题（Ionic `collapse="condense"`） |
| 首页下滑 | 滚过车名后，顶部出现磨砂栏“车名 / 82%　已锁车”，透明度 0 → 1，150 ms，跟随滚动 |
| 按压 | 所有可点元素按下时缩放到 0.96，透明度 0.85，80 ms；松开用 `spring` 回弹。列表行按下时背景变为 `--fill`，不缩放 |
| 弹层 | Ionic sheet modal，高度按内容自适应；可下拉关闭；遮罩淡入 250 ms；关闭跟手 |
| 滑动条 | 见 4.1 |
| 数字变化 | 只有拿到新数据、数值确实变化时才动：每一位数字从下方 8 px 处滚入并淡入，300 ms `out`，每位间隔 30 ms。首次加载不动 |
| 车图 | 首次加载完成：透明度 0 → 1，缩放 0.98 → 1，500 ms `out`。数据变旧：去饱和、降透明度，600 ms。换车：旧图淡出 150 ms，新图淡入 |
| 充电光 | 车底绿光透明度 0.55 ↔ 1，2.4 s 循环；地面亮线从左向右流动，2 s 一次。只在接口报告“充电中”时出现 |
| 下拉刷新 | 首页和各记录页支持。下拉时 G 标的滑块沿横杠滑动，表示拉动进度；松手后横杠旋转，直到拿到结果。结果出来后收起，250 ms |
| 结果提示 | 从顶部安全区下方滑入（`spring`），停留 2.5 s，向上滑出；用户上划可提前关闭 |
| 加载占位 | 首次加载时，读数位置显示 `--fill` 圆角块，带 1.2 s 的光泽扫过动画；刷新时保留旧数据，不显示占位 |
| 列表增删 | 新增项高度展开加淡入 250 ms；删除项向左滑出后收起 |
| 减少动态效果 | 关闭所有位移和缩放，只保留 150 ms 淡入淡出；充电光改为静态；数字直接替换 |

### 3.3 触感（只在 App 中）

在原生容器新增桥接方法 `haptic(type)`：iOS 用 `UIImpactFeedbackGenerator` / `UINotificationFeedbackGenerator`，Android 用 `View.performHapticFeedback`。网页版不震动。

| 时机 | 类型 |
|---|---|
| 滑块拖过 70% 生效点 | `medium` |
| 车辆确认执行成功 | `success` |
| 未收到车辆响应、操作失败 | `warning` |
| 开关切换、分段切换、选择器滚动到新值 | `selection` |
| 下拉刷新拉到触发点 | `light` |

## 4. 组件

组件放在 `src/components/`，每个组件一个 `.vue` 文件。能用 Ionic 组件的一律用 Ionic，只做主题定制。

### 4.1 滑动条 `SlideControl`（品牌核心组件）

界面图：滑动条全部状态（见工作区 docs/design/v2/，设计图不随网站发布）。

**外观**
- 整宽（屏宽减 40），高 64，全圆，底色 `--fill`。
- 滑块直径 54，距边 5，底色 `--knob`（浅色白、深色 `#F5F5F7`），带阴影，图标 22。
- 槽内文字 16 / 500，颜色 `--t2`，在滑块以外的区域居中。
- **闲置时**，文字上有一道 1.6 s 的高光从左扫到右，每 4 s 一次（同 iPhone“滑动来解锁”）。“减少动态效果”下关闭。

**交互**
- 滑块 1:1 跟手；拖到两端外时有 0.3 倍的橡皮筋阻力。拖动时，文字透明度随距离从 1 降到 0（拖到 40% 时为 0）。
- 拖过槽长 70% 时触发 `medium` 触感。在 70% 之后松手，滑块用 `snap` 吸附到终点，指令开始发送；在 70% 之前松手，用 `spring` 弹回。
- 用 `touch-action: pan-y` 加指针事件接管横向拖动，不能和页面纵向滚动、iOS 边缘返回手势冲突（拖动起点距屏幕左边小于 24 px 时，交给系统返回手势）。
- **点击滑动条**（不拖动）：打开确认弹层（4.3），作为不方便滑动时的替代方式。
- **键盘和读屏**：读屏读作按钮“上电开锁，需要确认”；回车键打开确认弹层；左右方向键直接触发对应方向的动作。

**状态**

| 状态 | 滑块位置 / 图标 | 槽内文字 | 样式 |
|---|---|---|---|
| 已锁车（数据新鲜） | 左 / 锁 | 滑动上电开锁 | 默认 |
| 未锁车（数据新鲜） | 右 / 开锁 | 滑动关机锁车 | 默认 |
| 状态未知或数据过期 | 中 / 双向箭头 | 左“‹ 锁车”，右“开锁 ›” | 默认，两个方向都能滑 |
| 发送中 | 终点 / 转圈 | 正在开锁、正在锁车 | 槽变为 `--ink`，文字 `--ink-t` |
| 已发出，等待车辆 | 终点 / 时钟 | 等待车辆响应 | 同上 |
| 完成 | 终点 / 对勾（滑块变 `--energy`、白色对勾） | 已开锁、已锁车 | 默认；1.2 s 后进入新状态，触发 `success` 触感 |
| 未收到车辆响应 | 中 / 警示 | 左“‹ 锁车”，右“开锁 ›” | `--attn-bg` 底，1.5 px `--attn` 内描边；触发 `warning`。不自动重发 |
| 不可用 | 原位 | 直接写原因：网络不可用、请先登录、此车型不支持、演示中 | 整体透明度 0.42，不可拖动 |

- 业务对应：开锁调用原有的 `powerOn`，锁车调用原有的 `powerOff`。“完成”必须读到车辆的新锁状态才显示，沿用现有回读逻辑。
- 多车账号：滑动条本身不显示车名（首页顶部已经有车名），确认弹层里显示。

### 4.2 圆形快捷键 `QuickAction`

- 直径 58，底色 `--ctl`（浅色白加阴影，深色 `#1C1D21` 加顶部高光），图标 24；下方 8 px 处是标签，13 号，`--t2`。
- 四个一排，均分宽度（左右边距 12）。
- **忙碌**：图标换成转圈，标签不变。
- **不可用**：透明度 0.42；点击时顶部提示原因，不弹窗。

### 4.3 弹层 `Sheet`

- 用 `ion-modal`，设 `breakpoints=[0,1]`、`initialBreakpoint=1`，高度按内容自适应。
- 外观：距屏幕左、右、底各 8 px，圆角 38（像 iOS 的浮动卡片）；顶部拖拽条 36 × 5；内边距 20。
- 标题 22 / 700 左对齐，右侧是 32 px 的圆形关闭按钮（`--fill` 底，`x` 图标 14）。确认弹层例外：标题居中，不放关闭按钮。

**确认弹层**（座桶、储物箱、滑动条点击、修改设置、删除，见图 16）
- 顶部 64 px 圆形图标，然后是标题（动作本身）和一行目标“车名　尾号 3A9F21”。
- 修改设置时，第二行写“从 5 分钟 改为 10 分钟”。
- 主按钮写动作全名，次按钮写“取消”（透明底）。
- 危险操作的主按钮用 `--alert` 底、白字。

### 5.12 消息 `/vehicle/messages`

## 6. 文案

### 6.1 原则

- 像车在跟你说话：主语省略，动词在前，一句话说完。
- 状态用“已 / 正在 / 未”开头：已锁车、正在充电、未锁车。
- 时间用相对时间：刚刚、3 分钟前、2 小时前、昨天 14:20、11 月 6 日、2025 年 11 月 6 日。
- 数字格式：
  - 千位加逗号（8,818.9），小数最多 1 位；
  - 单位前加一个空格（91 km、2.4 bar、24 °C），`%` 例外（82%）；
  - 范围用“—”（08:10 — 08:38），变化用“→”（31% → 100%）。
- 并列的两条信息用全角空格隔开，**不用“·”“｜”“/”**。
- 禁用词：云端、接口、API、原生、桥接、缓存、上报、回读、回执、字段、契约、能力、合成、模拟（演示器除外）、脱敏、Safari、PWA、IPA、APK、WebView、token（token 登录入口除外）、VIN（写“车架号”）、请求、服务端、客户端、操作失败、未知错误、请稍候、暂无数据、成功（车辆确认之前）。

## 8. 状态与业务规则（不变，集中列出）

- **数据新鲜度**：车辆上报超过 30 分钟算旧数据；时间异常（比本机快 5 分钟以上）或未知时，也按旧数据处理，锁状态视为未知。
- **车控**：开锁、锁车、座桶、储物箱、寻车，都要先确认（滑动本身就算确认）。发送中不能重复发送；结果不确定时不自动重发；读到车辆新状态才说“已开锁”。
- **切车、切账号**：立即清掉旧读数。
- **地图**：只在用户点开时才把坐标发给高德。
- **登录信息**：只在本机加密保存；token 默认遮挡；账号备份必须设密码。
- **演示模式**：不调用任何接口和原生能力，不改真实账号和偏好。
